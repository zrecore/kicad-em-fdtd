# Papers this project cannot read: what they claim, what we could check, and where

*In-house register, 2026-11-23 (requested by the user: get the abstracts, prove the claims, explain the proofs, reproduce where possible). **Rules followed:** only open metadata services were used (OpenAlex, Crossref) and the publishers' public pages; no paywall was circumvented; the abstracts below are paraphrased in this register's own words, never stored verbatim (they are the publishers' text); nothing from a paper's full text is used because none was read. A claim in an abstract can be (a) a description of what the paper does, which is not provable but can be reproduced by measuring the same quantity with this project's solvers, (b) an accuracy bound on a formula we do not have, which cannot be checked against the formula but whose quantity we can measure and publish with our own error bar, or (c) a theorem, which can be proved.*

## What this register does not claim
No result here reproduces a paper's own table or formula. Where a paper's formula is implemented in the project it was taken from open secondary sources and is described as such in the code; the tests here measure how good it is against an independent numerical solution, which is a different statement from "the paper's claim holds". The full texts remain unread; if they are obtained, each note's "not checkable" and "not compared" items are the first to redo.
